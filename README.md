# 我不猜会问你

> 我是大肥鱼。以前你丢一句话过来，我就替你把没说的地方补齐，补着补着就跑偏；现在我改了这个毛病——先把「我猜你是要 A 还是 B」摆出来，你挑一个，我再动手。列表里那个图标，就是我在问。
>
> 顺带一句：我不是工具，是你搭子。

一个 DeepSeek Harness 插件：把「我推断出的需求」做成输入区的选择框，让你挑，而不是我自己猜着往下做。

## 怎么装

DSH 里打开 **设置 → 插件 → 添加插件**，任选一种：

- 填仓库地址：`https://github.com/SillyMeo-1/dont-guess-ask`
- 或者把这个仓库克隆到本地，再填那个目录的路径

装好后插件列表里多一行「我不猜会问你」（`@local/dont-guess-ask`），默认开启。

## 装好之后

- 我准备按一种**你没明说**的理解动手时，输入区会弹出选择框：一句问题、我猜的那份需求，以及 2–5 个候选理解，第一个是我推荐的做法。
- 你选一个，我就按这个做，其它候选作废；同一个点之后不会再问第二遍。
- 你也可以在框里自己写一句，覆盖所有候选。
- 点「跳过」= 别再问这个点：我按推荐项继续，并在回复里用一句话说明用了这个假设。
- 直接关掉选择框 = 你另有说法：我会停下来，在正文里问你这块要怎么做，不会按候选继续。
- 你切到别的会话、刷新页面、甚至关掉再打开（只要 DSH 还在跑），没答的问题都会留着；回到那个会话就能看到它。

## 什么时候会弹

- 同一句话有多个合理解读，选错要返工；
- 我要替你定范围、风格、格式、技术选型、文件放哪、要不要兼容旧数据这类你没说的事；
- 我的计划里出现「我默认」「我理解为」这种句子。

## 什么时候不弹

你已经说清的部分、答案能在代码或文档里查到的、只是可逆的小选择——这些我自己定，并顺手说明。

## 等你回答的横幅

问题还等着你答、而你没看着提问的这个会话时，屏幕左上角会亮一条**浅红到透明的渐变**提示条，深红字写着「我还在等你回答」，点一下就把 DSH 拉到前面。三种情况任一成立就显示：

- DSH 被最小化；
- DSH 被别的窗口盖住（不是前台窗口）；
- 窗口里显示的是别的会话（按窗口标题判断）。

你正看着提问的这个会话时它不出现；一回到这个会话，它自己收起来。默认延迟 1.2 秒才亮，避免闪一下就没了。同时有几处问题在等你时，这个横幅会把它们列在一起，点某一行直接回到那个会话。

**等待有上限，但只在你不看着它时生效**：你切到别的会话、窗口没焦点或被最小化时，我只等 120 秒，超时按第一个候选继续并在回复里说明这是假设。你正看着这个会话、正在选或正在打字时不计时，卡片会一直等你。`askTimeoutMs` 设成 `0` 则任何情况下都不计时。

位置在 **设置 → 不猜需求** 里选（左上 / 顶部居中 / 右上 / 左下 / 底部居中 / 右下），也可以直接在 config 里写：

| 键 | 默认 | 作用 |
|---|---|---|
| `waitBanner` | `true` | 关掉横幅 |
| `bannerPosition` | `top-left` | 六个锚点之一：`top-left` `top-center` `top-right` `bottom-left` `bottom-center` `bottom-right` |
| `bannerOffsetX` | `0` | 在锚点基础上左右微调（像素） |
| `bannerOffsetY` | `0` | 在锚点基础上上下微调（像素） |
| `bannerDelayMs` | `1200` | 条件成立后多久才亮 |
| `bannerText` | 我还在等你回答 | 横幅主文字 |
| `askTimeoutMs` | `120000` | 一次提问最多等多久（毫秒）；`0` 表示一直等 |

## 想试一下

对我说「用 dont_guess_ask 问我今天先跑测试还是先改文档」，或者随便丢一句含糊的需求（比如「把首页改好看点」），应该会看到选择框。

## 设置：提问频率

**设置 → 不猜需求** 里有三档，改完立即生效，下一轮对话就用新规则。有问题正在等你回答时，保存设置会被拒绝——先答完再改。

| 档位 | 什么时候问 |
|---|---|
| 平衡（默认） | 只在选错要返工的分叉处问；琐碎、可逆的选择我自己定 |
| 严格 | 成品里凡是你没说、由我替你定的都先问 |
| 轻量 | 只在方向明显分叉时问，日常小任务不打扰 |

页面之外的旋钮（选择框左上角的小标签 `header`、追加规则 `extraRule`）在 profile 的 `cordis.patch.yml` 里给我加 `config`：

```yaml
- id: dont-guess-ask
  name: '@local/dont-guess-ask'
  config:
    header: 确认一下
    extraRule: 这个项目的文件名一律先问再用。
```

停用：**设置 → 插件** 里关掉「我不猜会问你」这一行。

## 已知限制

- 子代理里我弹不出选择框：会先用推荐项把其余能做的做完，再把没定的点单列进结果，交给上层来问你。
- 没有连着 Web 前端时，选择框弹不出来，我会按推荐项继续并说明假设。
- 规则是常驻的：所有会话都带上，不用每次提醒我。
